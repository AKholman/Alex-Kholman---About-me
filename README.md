### 🚀 Featured Projects (ML & GenAI Systems)

#### 1️⃣ Autonomous Fraud Investigation Agent

Built an agentic fraud investigation system using LangGraph and XGBoost, integrating fraud prediction, SQL transaction analysis, and Qdrant-based policy retrieval (RAG). Implemented multi-step evidence analysis, risk-based decisions, investigation reports, FastAPI serving, PostgreSQL/Redis persistence, observability, and a Streamlit dashboard supporting human review.
**Tech:** Python, LangGraph, XGBoost, Qdrant, FastAPI, PostgreSQL, Redis, Streamlit, Groq LLM

#### 2️⃣ Personalized Recommendation System

Built an end-to-end recommendation pipeline using BigQuery for preprocessing, Google Cloud Storage for data storage, and streaming Parquet data for scalable training. Developed a PyTorch Two-Tower retrieval model with Qdrant vector search and a Deep & Cross Network (DCN v2) ranking model, with FastAPI serving Top-10 personalized recommendations.
**Tech:** PyTorch, BigQuery, GCS, Qdrant, DCN v2, FastAPI

#### 3️⃣ Production RAG System with Cloud Observability

Built an end-to-end RAG pipeline using MiniLM embeddings, FAISS retrieval, and Groq-hosted LLaMA-3.1-8B. Implemented a Colab-to-AWS architecture with S3, EC2, FastAPI, and CloudWatch observability, including structured logging, latency decomposition, token usage tracking, and p95 latency analysis. Validated serving behavior with 60+ request tests.
**Tech:** Python, Sentence-Transformers, FAISS, FastAPI, AWS EC2/S3, CloudWatch, Groq LLM

#### 4️⃣ Real-Time Fraud Detection System

Built an end-to-end credit card fraud detection pipeline for highly imbalanced data. Used Databricks and Spark/SQL for preprocessing, trained XGBoost models, and implemented serverless inference using AWS Lambda and API Gateway, with a Streamlit interface for real-time predictions.
**Tech:** XGBoost, Spark, SQL, Databricks, AWS EC2/S3/Lambda, API Gateway, Streamlit

#### 5️⃣ LLM Fine-Tuning & Inference (Mistral-7B + LoRA / QLoRA)

Fine-tuned Mistral-7B using LoRA/PEFT on a Google Colab T4 GPU. Built mixed real and synthetic instruction-tuning datasets and deployed a 4-bit quantized FastAPI inference service. Evaluated model behavior and analyzed limitations related to dataset scale and instruction alignment.
**Tech:** PyTorch, Transformers, PEFT, QLoRA, FastAPI
